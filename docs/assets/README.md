# Showcase Visual Assets Guide

This directory is reserved for demo GIFs and screenshots referenced by the root `README.md`.

## Recommended Assets
1. `demo.gif` — 8–12 second loop showing: Desktop chest search → launching Palworld → toggling the in-game overlay with the hotkey → clicking a chest on the live radar.
2. `desktop-chests.png` — Desktop window showing chest contents & base radar.
3. `ingame-overlay.png` — Transparent in-game overlay over Palworld gameplay.

## Activation
Once you place `demo.gif` (or screenshots) in `docs/assets/`, uncomment the image tag near the top of `README.md`:

```markdown
![Palcore Demo](docs/assets/demo.gif)
```
