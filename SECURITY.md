# Security Policy

## Reporting a Vulnerability

Because Palcore's source code is maintained in a private repository and distributed via the Overwolf App Store, please **do not** disclose security vulnerabilities in public GitHub Issues.

Instead:
1. Use GitHub's **Security → Advisories → Report a vulnerability** feature in this repository (when enabled), **or**
2. Contact the developer via the support email listed in [PRIVACY.md](./PRIVACY.md).

Please include:
- Steps to reproduce the issue
- Palcore version and Overwolf client version
- Potential impact (e.g., local file handling, window behavior, or data exposure)

Reports are reviewed as promptly as possible, and patches are shipped through the Overwolf App Store auto-update channels.
